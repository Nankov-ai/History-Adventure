# History Adventure 🏛️🎮

Jogos interativos para aprender História e Geografia de Portugal (5º ano).

🔗 **App online:** https://nodeflow.pt/History-Adventure/

Aplicação estática (HTML + CSS + JavaScript), sem dependências nem servidor. Não recolhe dados: só a melhor pontuação fica guardada no próprio browser.

## Créditos

Os contornos de Portugal e Espanha em `assets/pt.svg` e `assets/es.svg` vêm do projeto gratuito [mapsicon](https://github.com/djaiss/mapsicon) de djaiss.

Feito por [Nodeflow](https://nodeflow.pt).
